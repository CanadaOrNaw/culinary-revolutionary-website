# Handbook ownership

This handbook explains safe maintenance, architecture, implemented interfaces and evidence limits for the Culinary Revolutionary website. Canonical facts stay with source and existing owner records. Private business/customer/account records are not copied here.

- Reader source: Markdown, project-local `sidebar.json` and explicitly approved assets under `docs/handbook/`.
- Private verification: source/interface/page/example/task map and exact review evidence under `docs/verification/`; not reader-site input.
- Historical products: retained `_generated/` HTML/PDF/receipt are script-owned old views, excluded from the new source set and never hand-edited.
- Shared portal: reads independently accepted project inputs. It does not own a rival culinary source tree or authorize publishing the business site.

Root contracts still govern outward publication. The [collaboration overview](collaboration.md) points to launch/client-decision authorities. The [maintenance guide](maintenance/change-impact-and-docs-ownership.md) explains integrity versus correctness review and parent-owned generated-policy integration.

Start at [index](index.md), use [working routes](guide.md), and read [status](status.md) before relying on a result. This author snapshot is changes-required until independent review; a build or digest cannot accept it.
